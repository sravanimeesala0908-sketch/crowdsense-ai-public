# Crowdsense Ai Public

Build a polished, student-project-ready responsive web application named “CrowdSense — Crowd Prediction in Public Areas”. This is a Data Science project demo. Make it visually impressive and easy to show to a teacher: dark navy background with indigo/teal gradients, clean glass-style cards, subtle crowd/area illustrations, strong typography, responsive mobile and desktop layout. Add a dashboard with area selector (Bus Station, Railway Station, Shopping Mall, Market, Public Park, Beach), hour/time selector, day type (weekday/weekend), weather selector, and special-event toggle. A clear “Predict Crowd” action updates a results panel with Low/Moderate/High level, estimated crowd index, and practical advisory (e.g. less busy / moderate activity / likely busy). Include a chart visualization or timeline of estimated crowd levels by hour, a simple recent predictions panel, and a visible “Demo estimates — not live sensor data” explanation. Use a transparent illustrative heuristic for predictions (not fabricated live data and don’t claim real ML model accuracy). Add a compact About/Method section explaining crowd estimation inputs and possible use for safer trip planning. Must be functional with client-side state, polished, no login, no external API keys required. Ensure all page content works and feels unique, like an actual student project presentation, not a generic template.
